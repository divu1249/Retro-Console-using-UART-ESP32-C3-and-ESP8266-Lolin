# Pin Mapping

## ESP32-C3

| GPIO | Connected Component | Function/Pin |
|---|---|---|
| 20 | UART RX | Receive data |
| 21 | UART TX | Transmit data |
| 10 | TFT display | RST |
| 7 | TFT display | CS |
| 6 | TFT display | DC |
| 5 | TFT display | SCL |
| 4 | TFT display | SDA |

## ESP8266

| GPIO | Connected Component | Function/Pin |
|---|---|---|
| 4 | Buttons | UP Button |
| 0 | Buttons | LEFT Button |
| 2 | Buttons | RIGHT Button |
| 13 | Buttons | DOWN Button |
| 15 | Buttons | A Button |
| 16 | Buttons | B Button |
| 14 | Buzzer | To Buzzer's +ve Terminal |
| 12 | Motor | motor driver pin |
| A0 | Battery measurement circuit | unverified(check lolin model) |
